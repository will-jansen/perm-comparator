⚙️ Setup Required

warning

Your Salesforce Permission Comparator needs to be configured with a Salesforce Connected App before you can use OAuth2 login.

🔧 Step 1: Create a Salesforce Connected App

  1. Log into your Salesforce org
  2. Go to Setup → App Manager
  3. Click "New Connected App"
  4. Fill in the basic information:
    • Connected App Name: Permission Comparator
    • API Name: Permission_Comparator
    • Contact Email: Your email
  5. Enable "Enable OAuth Settings"
  6. Set Callback URL to:
    https://perm-comparator-reloaded-ef9f76256418.herokuapp.com/login/oauth2/code/salesforce-prod
    https://perm-comparator-reloaded-ef9f76256418.herokuapp.com/login/oauth2/code/salesforce-sandbox
  7. Select OAuth Scopes:
    • Full access (full)
    • Refresh token (refresh_token)
  8. Save and continue

🔑 Step 2: Get Your Connected App Credentials

After creating the Connected App:

  1. Go to App Manager and find your app
  2. Click "View" on your Connected App
  3. Copy the Consumer Key (this is your CLIENT_ID)
  4. Copy the Consumer Secret (this is your CLIENT_SECRET)

🌐 Step 3: Configure Heroku Environment Variables

Run these commands in your terminal:

heroku config:set SALESFORCE_CLIENT_ID="your_consumer_key_here" --app perm-comparator-reloaded
heroku config:set SALESFORCE_CLIENT_SECRET="your_consumer_secret_here" --app perm-comparator-reloaded
warning

⚠️ Important: Replace "your_consumer_key_here" and "your_consumer_secret_here" with the actual values from your Connected App.

✅ Step 4: Test the Application

success

Once you've completed the above steps:

  1. Wait 1-2 minutes for Heroku to restart with the new environment variables
  2. Return to the main page
  3. Click "Login Production" or "Login Sandbox"
  4. You should be redirected to Salesforce for authentication

🐛 Troubleshooting

  • Still not working? Check that your Connected App callback URLs exactly match the ones above
  • Getting authorization errors? Make sure your Connected App has the correct OAuth scopes
  • Need help? Check the GitHub repository for more information
